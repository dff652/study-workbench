# 真实家庭 Web 小批次验收

36 整合版本已运行，工程和运行结果见 [部署验收](reviews/web-deployment-20261005.md)。本清单准备真实使用反馈；尚未取得真实家庭试用结果，不能用合成账号、生成答案或浏览器脚本替代。

先由家庭确认一份真实资料、约两道题及实际学习者。现有几何小样可作候选，但资料和学习者归属需要确认；不自动迁移全部照片或补造作答记录。操作路径见 [PC 使用说明](pc-usage.md)，第一期完成条件见 [Web 清单](web-phase1-release-20261005.md)。

## 操作和通过条件

| 顺序 | 实际操作 | 留下的证据和通过条件 |
| --- | --- | --- |
| 1 | 使用已授权账号在电脑浏览器登录，确认家庭／学习者，展开“家长协助”进入“资料整理” | 登记 OS／浏览器、日期、运行版本；账号只能看到获授权家庭，刷新后归属正确 |
| 2 | 选择已核定资料，保留原照片，按原图核对题干、区域、题号、小问和答案 | 原图→题目、题目→原图及知识关联可反查；看不清、未知作者或依据不足继续待补；印刷错误与学习者错误分开 |
| 3 | 整理讲解，等待私人草稿保存，刷新后比较恢复；明确保存新版本，再生成讲解 PDF／Word | 草稿不新增正式历史；正式版本保留来源和方法，旧版本仍可读；实际查看页序、公式、图示、来源和分页。未实开 Microsoft Word 保持未测试 |
| 4 | 从“文档中心”制作配套的无提示练习；学生独立完成或如实登记获得的提示 | 实际下载和打印／屏幕题面可用；家长答案不混入无提示练习；生成讲解不创建学习者作答 |
| 5 | “学习档案”保存这次真实作答及独立评价，在“进度与复测”安排并记录实际复测 | 作答日期、原图／笔迹来源和课堂／提示／独立条件有依据；复测新增记录，原作答与评价不覆盖，计划完成不直接标为掌握 |
| 6 | 回看报告、历史和下载，反馈卡住或误解的操作 | 所选资料／学习者范围正确，未知仍为未知；问题登记具体步骤、预期与实际结果，必要时保存私有截图 |

实际复测可以分日完成；尚未发生时保留待测，不填写未来结果。模型可以始终关闭，人工流程应能完成；真实模型质量、费用和外发验证另行登记。

## 私有记录

照片、个人资料、作答、截图和详细反馈留在家庭私有记录中，源码文档仅登记去敏的完成状态。试用记录至少包含实际客户端／日期、所用资料与学习者、上述各环节的结果和未知项、具体问题、Word 的实际客户端及结果，以及确认人；缺少结果的环节保留“未测试／待反馈”。

只有这些真实环节完成、实际阻断问题修复并回归后，才更新第一期产品完成状态。Android／手机专项与 PWA 真机归第二期。
