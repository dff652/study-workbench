# PC 工作台与逐题解析契约

实现对应 [PC-01～10](pc-product-integration-plan-20261005.md)。本文件描述本地源码；运行验收、提交及部署以 [DEV_STATE](../DEV_STATE.md) 为准。

## 页面与权限

`/app/` 保留同一侧栏和顶栏。`view`、`household`、`learner`、`screen` 保存导航上下文；具体记录支持刷新和前进／后退。业务表单经 `app/api/workspace.py` 白名单分派到原 Django view，只返回过滤后的主内容。原导航、样式、脚本不进入页面，不使用 iframe。选区、排序和派生操作仅运行三个固定的本机控制器。

`GET /api/v1/workspace/page/?url=...` 读取内容，`POST /api/v1/workspace/submit/?url=...` 提交原字段及文件。表单的来源、上下文和幂等凭据保持；无效输入仍返回当前表单。登录、家庭权限、CSRF、方法限制与服务事务由原接口继续执行。资源通过独立私有读取接口访问，普通页面只展示中文状态、题号、摘要及可操作的来源链接。

页面另返回可选 `page.scope`（`household_id`、`learner_id`）。在原 view 完成授权后，从资料／题目／档案／作答／评价／复测的已保存身份读取范围；没有明确学习者的页面使用空 `learner_id`，不推断未知作者。主框架用实际范围替换陈旧的外围选择，保留当前页面及历史地址；列表进入、直接地址及刷新遵循同一规则。已离开的页面响应不能更新当前上下文，归一化不重新创建正在操作的表单节点。

## 草稿与历史

`swb.solution.v1` 历史与新编辑契约 `swb.solution.v2` 均由 `app/solutions/schema.py` 校验。包含资料内的讲次、题目及稳定局部标识；题目可关联本家庭的正式题目版本，也可先独立整理。题目保存有序来源、小问父子关系、题干完整程度、答案及单位、思考提示、本讲／其他解法、步骤、公式、易错点、图示、知识关系、勘误及未知事项。空缺可存草稿；未知答案、单位和区域保持未知。

v2 的本讲步骤与其他解法步骤分别保存稳定标识、文字、可选公式、可选图示和明确换页标记。每一步按文字→公式→图示编排；移动步骤同时移动其内容。打开 v1 仅转换可编辑副本，不回写历史；旧独立公式和图示保留原顺序，不猜测对应哪一步。重新保存才追加 v2 版本，旧下载及历史继续可读。

`WorkspaceDraft` 按家庭、账号和工作位置隔离，自动保存未完成输入；它不是正式内容修订。恢复前明确比较，冲突不自动覆盖；清空写入带版本的墓碑，迟到保存不能复活旧输入。通用表单只保存允许的业务输入，排除密码、令牌、隐藏请求字段、文件内容和 GET 筛选条件；文件刷新后需重选。

点击保存才追加 `SolutionRevision` 版本，`expected_version` 拒绝覆盖别页的新内容，同一 `request_key` 重放不追加。`SolutionConfirmation` 单独记录人工对照，不能代替原题审核或输出检查。`SolutionAsset` 与 `SolutionOutputEvent` 同样不可改写，PostgreSQL trigger 拒绝更新／删除历史。编辑不会创建孩子作答、评价或掌握结论。

知识、主要方法、辅助方法与题型使用明确的版本关联。主要方法最多一个；关系类型必须与节点类型一致，不能凭正文标题推断。生成内容显示所关联条目的名称，快照保存完整版本身份。题目版本、关联条目、页序、原图或已用资源变化后，旧内容不能直接重新生成，须先比较并保存新版本。关联题目还须属于当前资料；确认、生成、重试及后台生成前后均要求关联内容为当前已发布版本。撤回或被新版本替代的内容仍可回看，不允许重新确认或输出。

印刷错误、命名调整、草稿修正分别保存原文、替换内容及依据。这些是解析的修订说明；对正式题目的印刷勘误仍使用既有勘误流程，不以解析编辑自动改写原题。

## 固定 skill 与资源边界

纯内容校验／编排固定到 study-material-workflow 提交 `72e9a3d178859d47581db17a71bee3babaa31ee8`。四个所需模块封装在 `app/solutions/vendor/`；`SOURCE.json` 记录源路径、原 SHA、相对导入适配及适配后 SHA，运行时核对。没有从远端自动更新工具，也没有导入另一套 PDF 引擎。

适配器编译为 `swf.solution-companion.v1`，使用原生字体、公式及 PDF／DOCX 渲染器。三种组织方式先对每题测量分页，再复用相同题目正文；合集目录显示讲次名称。原生渲染器版本为 `a2.v4`；完整生成器、字体、内容、来源和输出摘要留在清单中，正文页脚显示中文状态与页码。

companion PNG 与既有 v2 配对教学图分开：最多 8 MiB、400 万像素，存入资料私有目录。页面的整张来源图与裁切图由服务端从不可变原图／区域生成，再逐像素校验，保留透明通道；不从白底展示预览或浏览器 canvas 生成来源素材。辅助图仍需上传，改绘图只能标为辅助图，并填写依据。图示来源必须属于该题的来源列表。专用 `companion_image` 块只允许家长答案用途，不冒充已有矢量教学图，不进入无提示练习。

来源保存原文件摘要、页序、尺寸和 skill 来源映射。原照片字节不变；层级小问和跨页来源不展平。既有 `swb.skill-import.v1/v2` 继续使用原入口，本契约不替代旧交换包，也不接收未经映射的历史公式图片。

既有 v2 待确认包的教学 PNG 通过 `GET /api/v1/workflows/<id>/assets/?key=...` 在同页核对，读取前重新校验 PNG、摘要与家庭权限；SVG 不经此入口内嵌。公式树以可读数学式显示，来源引用以原图选区显示。历史解析引用的旧知识／方法保留名称、版本及详情锚点，继续回看当时来源。

## 后台任务与输出检查

生成请求绑定具体草稿版本，进入 `queued → running → output_check`。后台 worker 即使模型关闭也可以执行确定性文档生成。重试保持任务事件历史，每次 claim 使用新私有输出目录；迟到 worker 不得恢复已取消任务，失败不推进成功结果。运行超过 30 分钟的中断任务标记失败后可重试。生成前后重验权限与来源。

输出选择支持逐题、分讲、合集，以及 PDF、Word 和打包 ZIP。每页 PDF 都有图片预览；DOCX 保留可编辑公式，并检查压缩包、原生公式数量及外部资源。文件读取重新核对 SHA。ZIP 只装选择的 PDF／Word、说明及检查范围，不打包原始照片。

机器检查与五项人工记录分开：内容核对、数学复核、PDF 视觉、PC Word、macOS Word。机器生成后均为未验；前三项通过且无失败项才标记“检查已记录”。未做真实 Word 实开时保持 `not_tested`；LibreOffice 转换只记录自身版本与结果。检查失败阻止打包交付，预览保留以便修订。

主要接口：

| 方法与路径（均以 `/api/v1/` 开头） | 用途 |
| --- | --- |
| GET `drafts/<key>/?household=...` | 读取当前账号在该家庭的私人工作副本 |
| POST `draft-save/<key>/?household=...` | 按版本保存或清空私人副本，不追加正式内容 |
| GET `materials/?household=...&q=...&page=...&page_size=...` | 全资料服务端搜索及稳定分页 |
| GET `materials/<id>/solutions/` | 草稿、来源、历史、已用资源及输出 |
| GET `materials/<id>/solutions/history/?before=...` | 分页读取更早草稿及其历史关联名称 |
| GET `materials/<id>/solutions/outputs/?before=...` | 分页读取更早文档，保持历史可达 |
| POST `solutions/formula-preview/` | 原生可读公式预览；不写学习或草稿记录 |
| POST `materials/<id>/solutions/draft/` | 追加草稿版本 |
| POST `materials/<id>/solutions/actions/` | 独立确认或请求生成 |
| POST `materials/<id>/solutions/assets/` | 校验并上传私有 PNG |
| POST `materials/<id>/solutions/source-assets/` | 从授权原图／区域生成来源 PNG，保留原像素及透明通道；同请求键重放不重复 |
| GET `solutions/revisions/<id>/` | 读取历史版本以比较 |

| GET `solutions/assets/<id>/` | 授权读取 PNG |
| POST `solutions/outputs/<id>/actions/` | 取消、重试或记录检查 |

| GET `solutions/outputs/<id>/download/` | 核验后下载选择的 ZIP |

## 验证与数据恢复

五册第三册可选本资料题目的历次记录或该学习者全部历史；范围在后台任务创建时冻结，并进入输出来源清单。新界面默认本资料，旧未携带范围的请求保留全部历史语义及幂等指纹。没有学习者时仍生成待测清单。独立报告可按资料筛选，所有统计在同一范围内计算，网页、JSON 与 PDF／Word 链接保留范围。

必要回归包括跨家庭／只读拒绝、CSRF、草稿冲突及重放、来源变化、追加历史、取消竞争、失败重试、PNG 像素绑定、旧导出兼容、真实后台 PDF／Word 生成及检查隔离。PC 浏览器覆盖页面矩阵、三个桌面宽度、真实表单与来源交互；截图和合成导出留在 Git 忽略的私有 `artifacts/`。

数据库与整个私有资料目录必须配套备份。容器恢复样本包含私人草稿、v1／v2 解析修订、确认、PNG、后台事件、三种组织输出、字体及配方；空实例恢复后复核全表及文件，再通过原读取逻辑核验输出。不对已有实例原地恢复，不改写真实家庭资料。真实模型、完整家庭批次、MS Word、36 升级及源码交付分别记录，不由本机合成测试推断完成。
