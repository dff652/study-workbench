# PC 使用说明

日期：2026-10-05。36 已运行 Web 体验改版 `bed16d3`，侧栏业务入口常显，见 [运行验收](reviews/web-ux-deployment-20261005.md)。下方新增学科与知识讲解段落描述独立本机候选；源码和运行状态见 [DEV_STATE](../DEV_STATE.md)。首次启动、账号与家庭初始化见 [容器说明](container-deployment.md#first-local-start)。

## 学生自己使用与家长协助

首页先选择「选题练习」「查看讲解」或「复习安排」。建议先独立做题，再核对讲解；不会的地方可以保留。下方的「学习概况」和「作答记录」用于查看已有证据与历次记录。

首页同时提供「整理学习资料」「记录一次作答」及「查看学习记录」。侧栏六个业务入口始终显示，设置位于底部。小问号提供补充说明，鼠标悬停、键盘聚焦或触摸点击都能打开；按 Esc 关闭。必须完成的操作与错误仍直接显示在页面上。

## 一份资料的人工流程

1. 登录后打开 `/app/`，在顶部确认家庭与学习者；多个可选项时使用选择框。从侧栏进入「资料整理」，搜索所有资料并翻页查找，也可创建资料集。在「原图与进度」中上传照片；多图逐张处理，失败时重试对应图片。选中的资料、搜索和页码随 URL 保留。
2. 对照原图整理页序、区域与题目。旋转、裁切、遮白及增强另存派生记录，原照片保持。看不清或缺来源的内容保留待补。
3. 在「知识与题库」管理知识点、方法和题型，关联到明确题目版本，检查题目→知识及题目→原图能双向回看。
4. 需要成套练习时，在「文档中心」的「逐题讲解」选择资料，点击「制作五册资料」。选择学习者后，学习证据册默认使用本资料题目的历次作答，也可明确选择这位学习者的全部记录；未关联学习者时生成待测清单。核对无提示练习与家长答案用途，再生成 PDF／Word 和 ZIP；原成果仍能回看。「五册与练习」用于选题生成无答案练习及查阅已有成果。

## 学科与知识点讲解

这部分属于本机知识集成候选；36 当前运行的 UX 版本尚未包含它，状态见 [知识集成验收](reviews/knowledge-integration-20261005.md)。

1. 在「资料整理」打开「资料学科」，按已确认的课程或原页选择学校学科，填写分类依据，保存分类新版本。没有分类记录的旧资料保持「未分类」。资料列表及讲解资料选择可按最新学科筛选；后来分类不会改写历史文档。
2. 在「知识与题库」点击「整理知识点讲解」，或从「文档中心」的「知识点讲解」选择资料。打开「讲解文档设置」，填写学习层级和讲次，并另选「数学证明／科学观察／语言分析／人文证据」依据类别；学校学科不会替你选择依据类别。
3. 添加知识点，在「结论与来源」说明原页结论、完整结论、定义和适用条件。选择原页／基础／补充归属，记录真实原图来源与印刷页码；看不清的区域和页码保持未知。已有知识版本可关联，依赖须存在且不成环。
4. 在「证明与讲解」完整填写先想什么、方法或构造及目的、推导或依据、结论、易错与适用限制。结论须重述完整声明。数学说明一般证明；科学区分观察与推广范围；语言和人文解释具体文本及证据。可以添加原生公式、图示与分页，订正保留原文和依据。
5. 编辑只自动保存当前账号的私人草稿；「保存为新版本」追加正式历史。「明确确认讲解」核验完整内容和当前来源。「生成 PDF / Word」选择知识清单、逐知识点、按讲次或完整合集，每种独立选择格式；讲解不会新建题目、作答、评价或掌握记录。
6. 在「历史版本」只读比较旧内容。「用此历史内容继续编辑」把内容带回编辑区，随后明确保存才追加新版本。保存回执、分类或来源发生冲突时，先对照，当前输入不会被服务器内容替换。
7. 在「生成文件」查看任务、逐页预览和 ZIP，分别记录内容与来源、学科依据、PDF 版式、Windows Word、macOS Word。真实客户端未打开时保留「未测试」；任何检查失败会阻止 ZIP 交付。

三种模式的内容和审核边界见 [学科与模式契约](knowledge-subject-contract-20261005.md)。

## 逐题解析与文档

1. 「文档中心」→「逐题讲解」，选择资料，点击「查看讲解文档」。默认先看已有生成文件；需要整理时切换到「编辑讲解」。资料整理中的「讲解」也可打开讲解工作区。
2. 展开「文档设置」填写标题和讲次，再添加题目与小问；对照资料页，加入整页来源或点击「将原图选区加入本题来源」。跨页来源可分别添加；整页引用不会假造精确区域。
3. 补充题干、答案和解法。每一步可填写文字、公式、图示，并可上下移动或指定从新页开始；其他解法单独整理。公式直接预览，旧版未关联到步骤的公式与图片仍保留。补充信息按需展开；图示素材上传后，在需要的步骤中明确选择。
4. 编辑时等待「私人草稿已保存」。刷新后先比较，再选择恢复或丢弃；自动保存不会新增正式历史。检查内容后点击「保存为新版本」，才显示「已保存为版本」。冲突时比较并明确处理，不自动覆盖另一窗口的内容；切换到「历史版本」可打开对照，旧版本保持原样。
5. 在「文档设置」中选择逐题、按讲次或整份合并，以及 PDF／Word 格式，点击「生成 PDF / Word」。生成会先保存当前内容；每题须有来源和至少一个小问，关联题目与知识须为当前已确认版本。错误提示不会删除本地输入。
6. 在「生成文件」检查状态、每页图片及可用下载；仅选 Word 也有全页图片。任务可取消／重试；旧成果保持，生成失败或丢响应时复用原请求键。
7. 「逐项检查输出」分别保存内容、数学、PDF、Windows Word 和 macOS Word 检查。通过／未通过需写依据；未实际打开 Word 保留「未测试」。

逐题解析用途是家长答案，它不会建立学习者作答、评价或掌握记录。需要无答案练习使用对应五册入口，不能把解析文档当作独立作答题面。

## 真实作答与复测

顶部选择学习者，在「学习档案」保存每次实际作答的照片来源、日期与完成条件；笔迹作者未知时不猜。评价分别记录，修改追加版本，旧记录仍在。

「进度与复测」查看已有证据、安排复习计划并绑定真实作答。计划完成不等于掌握；重复练习保存为新记录。列表进入、直达或刷新学习者绑定记录时，顶部范围按获授权记录归属恢复。

家庭／学习者切换、刷新与浏览器前进后退保留具体记录地址；有未保存输入时按提示处理。只读成员可以查看获授权内容；会话过期后重新登录。未上传的浏览器文件刷新后需重新选择，不能把本机清单当成备份。

尚未提交的业务表单和资料整理输入可以保存为当前账号的私人草稿，重新进入后先比较再恢复。密码与令牌不保存为草稿，隐藏的提交凭据从当前页面重新获取。私人草稿、正式修订、人工确认是三个不同动作。
