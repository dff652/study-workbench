# PC 使用说明

日期：2026-10-05。适用于当前已验收的 PC 工作台源码；运行服务是否已更新见 [DEV_STATE](../DEV_STATE.md)。首次启动、账号与家庭初始化见 [容器说明](container-deployment.md#first-local-start)。

## 一份资料的人工流程

1. 登录后打开 `/app/`，在顶部选择家庭。进入「资料整理」，创建资料集并上传照片；多图逐张处理，失败时重试对应图片。
2. 对照原图整理页序、区域与题目。旋转、裁切、遮白及增强另存派生记录，原照片保持。看不清或缺来源的内容保留待补。
3. 在「知识与题库」管理知识点、方法和题型，关联到明确题目版本，检查题目→知识及题目→原图能双向回看。
4. 需要成套练习时，在「文档中心」使用五册入口。核对无提示练习与家长答案用途，再生成 PDF／Word 和 ZIP；原成果仍能回看。

## 逐题解析与文档

1. 「文档中心」→「逐题解析与文档」，选择资料，点击「打开逐题解析」。
2. 填写解析文档设置，添加题目与小问；对照资料页，加入整页来源或点击「将原图选区加入本题来源」。跨页来源可分别添加；整页引用不会假造精确区域。
3. 补充题干、答案、步骤与知识／方法关联。公式在页面可读预览；单位、区域或答案未知时继续保留未知。图示／来源 PNG 与原图绑定，辅助图片另有依据。
4. 等待「已保存为版本」；自动保存只追加草稿，不等于人工确认。冲突时检查服务器与本地内容，再明确保存新版本；「版本历史」可打开完整对照。
5. 选择逐题、按讲次或整份合并，以及 PDF／Word 格式，点击「生成 PDF / Word」。每题须有来源和至少一个小问；错误提示不会删除本地输入。
6. 在「生成文档」检查状态、每页图片及可用下载；仅选 Word 也有全页图片。任务可取消／重试；旧成果保持，生成失败或丢响应时复用原请求键。
7. 「逐项检查输出」分别保存内容、数学、PDF、Windows Word 和 macOS Word 检查。通过／未通过需写依据；未实际打开 Word 保留「未测试」。

逐题解析用途是家长答案，它不会建立学习者作答、评价或掌握记录。需要无答案练习使用对应五册入口，不能把解析文档当作独立作答题面。

## 真实作答与复测

顶部选择学习者，在「学习档案」保存每次实际作答的照片来源、日期与完成条件；笔迹作者未知时不猜。评价分别记录，修改追加版本，旧记录仍在。

「进度与复测」查看已有证据、安排复习计划并绑定真实作答。计划完成不等于掌握；重复练习保存为新记录。列表进入、直达或刷新学习者绑定记录时，顶部范围按获授权记录归属恢复。

家庭／学习者切换、刷新与浏览器前进后退保留具体记录地址；有未保存输入时按提示处理。只读成员可以查看获授权内容；会话过期后重新登录。未上传的浏览器文件刷新后需重新选择，不能把本机清单当成备份。
