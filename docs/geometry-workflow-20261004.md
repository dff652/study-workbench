## 教学图页面与版本

从已确认题目对应的家长答案页或资料集五册清单进入“核对教学图”：选本题原图区域 → 上传 PNG 与配套 PDF／SVG → 填写构造条件及核对依据 → 明确核对标签／条件及题面无提示 → 保存并确认。支持查看历史、原图反查和私有文件下载；目前上传已制作的图，不自动按照片重绘。

`TeachingDiagramRevision` 固定家庭、精确题目修订、题面／解析位置、序号、前序、文件哈希、原图区域与原图 SHA、构造条件、声明字号、核对者、时间及依据。每个题目版本的两个位置各取最新一张图；替换追加历史，不能覆盖、删除或自动继承到新的题目版本。旧题目版本页面可只读查看图示历史。多图组合需要制作成一张 PNG，尚无交互绘图器。

服务同时校验当前家庭写权限、已确认题目、版本上下文及幂等键；数据库触发器另行守护家庭、作者与追加链，并拒绝 UPDATE／DELETE。文件安装由锁覆盖持久事务，失败只清理本请求新建文件。原生迁移为 printing.0003，需在后续部署时显式执行，本机代码变化不会更新 36。

PNG 必须实际可解码，最多 1600 万像素；每个上传文件最多 8 MiB。SVG 限 UTF-8，只解析根元素并拒绝 DTD／实体，下载为附件，不执行、内嵌或用于浏览器渲染。PDF 只检查文件头；系统没有证明矢量文件与 PNG 的语义一致，必须人工核对。声明字号也不是自动图中文字识别。PDF／Word 都嵌入 PNG，Word 不承诺矢量可编辑。

题面图可进入知识、索引、练习与答案册；解析图只进入家长答案册。独立卷须明确确认整张题面图及打印条件无答案／方法提示；未确认时整套提前阻断。快照 provenance 与五册 manifest 固定本次图示版本及文件哈希；历史成套不随新图变更。ZIP 仍为 21 项输出，不是原图／矢量来源的完整备份。教学图属于打印域附属版本，不是作答证据，也不写入领域 Bundle；完整恢复依赖全数据库与私有文件联合备份。

## 真实小样口径

选一张照片的 W9-1(左)／W9-1(右)，每道保存公共指令和自己的图形区域，90°预览坐标转换回原图。题干指令按原文转录，原整题 10 分不重复分配为两个小题分值；重绘新增 A、B、C、D 仅作定位，数值及直角条件来自照片和题干。

- 左：共享斜边平方为 4²＋3²＝25，外层斜边平方为 25＋12²＝169，问号为 13。
- 右：共享斜边平方为 2²＋1²＝5，外层斜边平方为 5＋2²＝9，问号为 3。

题面图保留问号，不显示中间结果或答案；家长解析图另存。主代理核对转录、标签、条件及复算，不冒充家长确认。两题通过现有人工录题路径创建并与一个已核定方法双向关联；本次不验证旧索引导入节点直接进入 Web 编辑的衔接，也没有永久迁移。这是原题小样检查版，尚非独立变式命题或完整专题交付。

不创建学习者、作答、评价或勘误；第三册保留“未记录／未知”。没有笔迹不能推断独立掌握，两个答案正确也不能生成孩子成绩。

可重复的私有小样验证入口：

```bash

  --geometry-trial /absolute/private/trial-input.local.json \
  --geometry-output /absolute/private/new-output-directory \
  --browser --business-browser
```

仅使用本脚本创建的断网、无发布端口临时 PostgreSQL；退出清理数据库及临时运行文件，检查版输出保留在明确指定的新私有目录。输入由本机已核对的 JSON／图示提供，不执行历史脚本。该命令与参数不指向 36。
