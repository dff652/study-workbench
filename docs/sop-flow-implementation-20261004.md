# SOP 人工流程简化与五册编排

日期：2026-10-04。用户在 [SOP 对照评估](sop-implementation-assessment-20261004.md)之后同意继续实施。此记录说明本机源码变化；36 的运行页面、Git 提交和 NAS 交付另行记录，不能由源码变化推导。

本文记录先前人工流程批次；后续真实来源与教学图 Web 的新实现和验收边界见 [几何实施记录](geometry-workflow-20261004.md)，AI 核对及整页状态见 [后续实施记录](ai-continuity-20261004.md)。下文“尚未”及 284 源码冻结相关结论仅对应该先前批次。

## 本轮产品路径

人工路径为：创建资料集／上传原图 → 框选区域并录入题目 → **保存并确认题目** → 录入并复算家长答案，**保存并确认答案** → 从资料集进入“继续核对并生成五册” → 补齐清单、选择学习证据 → 生成 PDF／Word 和 ZIP → 人工检查版式。

确认与保存由同一事务衔接，仍追加内容版本和确认决定；失败整体回滚，重复请求不追加第二份记录。新版本不覆盖旧版本，过期编辑上下文拒绝。草稿入口保留；题干缺失不能一键确认。确认只代表家长核对内容，不能产生孩子掌握、作答或评价。

主导航保留资料、知识题库、学习档案、文档导出和复习报告，模型、合拆题、家庭成员及保留工具移到“设置与更多工具”。单家庭创建资料时自动固定家庭，服务器仍校验归属。没有切换前端框架、安装 shadcn-admin 或开发原生 App。

AI 任务尚沿用既有“提案／应用／复核”界面。自动展示核对页、批量确认和整页阅读／分区完成状态仍需后续实现，不能把本轮人工路径简化说成整个 AI 流程已经简化。供应商配置与真实调用继续由用户后续手动测试。

## 几何索引契约

[几何适配器](../app/imports/geometry.py)通过共享 CatalogProfile 接入既有转换器：

| 字段 | geometry.v1 规则 |
| --- | --- |
| book | J3、J4、W5～W9，有固定顺序 |
| num | 正整数 N、N(k)、N(k)-m、N(左)、N(右)；保存原题号，左右小问归同根父题，排序左先右后 |
| photo | 六位 token，以 `+` 分隔；原始顺序及父节点的有序来源并集保留 |
| aux | 调用者提供“精确名称 → 1～6 组号”映射；分号分隔，稳定去重；未知名称拒绝，不能按字面猜分类 |
| 内容与证据 | 九字段原行不变；缺题干、区域、作答来源继续为草稿／未知，不新增作答、评价或掌握 |

计算格式默认保持 `calculation.v1`：J1／J2／W1～W4、斜杠来源、数字辅助组。稳定身份仍由家庭＋dataset_key＋原 book／num 决定；两个专题须用不同 dataset_key，不把同组号当同一方法。

私有准备包 schema 继续为 `study-workbench.legacy-import.v1`。新包可在 `sources.profile` 保存完整 geometry.v1 映射，该值参与来源摘要；重建、校验、重复导入均按包内固定映射进行。映射变更不能替换同 dataset_key 的旧包。旧计算包未添加 profile，其原摘要和映射保持。

CLI 的 `prepare` 可显式传 `--catalog-path`、`--groups-path`、`--geometry-map`：前两项指清单中的来源路径，最后一项指私有 JSON 名称映射。继续只用 AST 读取 GROUPS，不执行历史脚本；prepare 会复制来源，应在实际迁移获授权后执行。本轮只验证合成准备包，没有准备或导入真实几何照片。

私有输入冻结已校验几何 JSON、GROUPS 脚本及来源清单快照：77 条索引、73 个根题号、33 条照片元数据，跨页行 W8-4／W8-10。原照片字节、尺寸和辅助名称的人工分类映射尚未全部核定，不能宣称 33 张真实来源已经通过导入验收。

## 教学图与五册输出契约

打印 schema 保持 `study-workbench.print.v0.1`，生成器追加为 `study-workbench.renderer.a2.v3`。新增 `diagram` 块，保留 `formula_image` 原规则，未知裸 image 块仍拒绝。

教学图需要 PNG 的本地 storage_key／SHA、矢量 PDF 或 SVG 的 key／SHA、source_ref、alt、打印宽度、构造 conditions、min_label_points 和 independent_safe。根目录边界、文件大小、PNG 解码及两份哈希分别校验；矢量只留作来源，SVG 不执行。PDF／Word 按比例嵌入 PNG，并显示图示来源及条件。min_label_points 是制作／人工核对声明（9～40 pt），不是自动识别位图字体的证明；图形关系、标签实际字号及正确性仍须验图。Word 图示为嵌入图片，不承诺可编辑矢量。

独立卷除既有角色白名单外，diagram 还要求本输入明确 independent_safe=true；该声明须确认所有标签、条件和图形没有答案／方法提示。原图公式回退仍用题目版本的 image_print_confirmed，不共用或自动沿用图示确认。

[五册编排器](../app/printing/packets.py)从资料集关联的题目当前头开始，禁止静默跳过待确认题目，要求每题有当前已确认题干和该题版本的已确认家长答案。家庭锁下构造固定题目版本的知识整理、分类索引、学习证据、独立复测和家长答案五个 ExportSnapshot；缺少知识关联时在文档和清单保留待补，整套标为待版式检查，不宣布正式完成。

单册普通导出仍限 30 题；成套入口明确限 150 题，由既有测量排版分页，每册最多 100 页，超限失败并提示拆分资料集，不丢题。没有自动多卷拆分。学习证据未选学习者时生成待测清单；选择学习者时第三册使用其完整历次记录，清单写明 `selected_learner_history`，不冒称只来自本资料集，也不把未记录历史补成作答。

成套清单 `study-workbench.five-books.v1` 固定资料集、家庭、题目版本、证据范围、知识缺口、五份快照及四类文件 SHA／大小。清单使用内容哈希命名、0600、排他创建；重复结果校验复用，冲突保留旧文件。ZIP 包含 10 份 PDF／Word、五份 content.json、五份 snapshot.json 和 manifest.json，共 21 项。每次打开或下载重新检查家庭访问、快照可用性及文件哈希；退役快照不能通过成套下载复活。

ZIP 是输出交付包，不是全项目备份，也不包含全部原图、字体或图示来源资源。完整恢复继续使用数据库＋私有数据联合备份。本轮没有 NAS 发布器、DeliveryRun、远端暂存或原子发布；本机生成不能标为 NAS 已交付。

## 轻量成员边界

所有者可在 `/members/` 新建审核／只读登录账号、调整非所有者角色、移除家庭访问。服务器重新检查当前 active owner；不能接管现有未知账号、修改所有者、调整 staff／superuser 或删除全局登录账号。移除成员只移除该家庭访问，保留账号、其他家庭与学习历史。创建使用密码哈希，错误事务不留下半个账号，表单不回显密码；不增加孩子登录、开放注册或复杂后台角色体系。

## 验证与剩余任务

主代理审查完整实际差异并独立验证；一个 luna6-worker 依次拥有纯几何适配和隔离的新成员模块，共享契约、五册、人工流程及最终验收由主代理负责。47 项纯转换／准备／导出、268 项全套数据库测试及最终 13 项五册／成员回归通过；系统检查、迁移无漂移与回退／重装通过。31 题成套覆盖普通导出 30 题上限之外的分页及完整性，未确认打印图片提前阻断。旧计算包 81 行的隔离重复导入、219 实体、原图哈希与双向追溯通过。Chromium 手机宽度基础 10 项、业务 65 项检查通过，无 JS 异常或业务外发请求；主代理查看五册页面及合成教学图 PDF。详细分阶段结果见 [DEV_STATE](../DEV_STATE.md) 的本轮实施段，失败中途结果保留但不算通过；实体手机、真实家庭和 MS Word 尚未验证。

用户最新安排为先更新项目文档并 review，后续统一 push；当前不提交、不推送、不升级 36。后续统一源码交付后，再执行已确定范围的 36 备份、恢复演练、升级及复验。真实资料迁移和 NAS 写入另行确定操作范围，本轮本机工程验收不自动启动这些操作。

本轮实际差异及只读独立复核已完成，结论和已验输入见 [SOP review](reviews/sop-20261004.md)；该结论仅覆盖本机工程修改，不扩大真实来源、模型或部署验收范围。
