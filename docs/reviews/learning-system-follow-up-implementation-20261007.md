## 实际改变

- **行动区与更新**：学习任务和证据区域的同级 React key 原先完全相同，学习者切换产生重复区域。修复前新增反例实际得到2个行动区，修复后保持1个；六个其他领域不残留。保存成功后按家庭／学习者发布更新，过期响应与失败保存不更新其他范围。
- **事件顺序**：总览、档案、报告、关联分组和复测最近记录共用规则：已知实际日期优先，同日真实前次关系优先，无关联按首次录入时间；未知日期最后，修订时间及随机标识不代表事件先后。显示排序依据，保留分支、撤回及替代历史。
- **成果查找**：文档中心默认最近成果，合并练习、知识讲解、家长解析、五册及报告后全局分页；跨类型搜索，提供预览、Word／ZIP及历史入口。失败检查和退役文件不显示可用下载。“整理”无输出直接进入编辑，“查看”已有输出直接进入结果。
- **学习任务**：默认学生练习，家长方式按当前账号保存且只影响呈现；权限仍由后端控制。总览先任务／最近记录，家长待办、规则和证据分析展开阅读；复测显示逾期／今天／近期及范围，最多3条。
- **练习与复测**：题目保持答案默认隐藏，保存时如实确认提示、作者、日期和来源；草稿／非当前可练习版本不能从学生直达绕过门槛，提交也不能替换当前任务题目。历史录入仍可如实绑定旧发布版本。保存回执提供返回题目／记录。复测计划带入对象，保存后明确待确认精确版本，人工确认才完成，重复确认保持幂等，不自动评价或认定掌握。“今天”和报告计划范围按北京时间计算，存储时间及实际作答日期不改。
- **继续整理与档案**：首先打开真实未完成题及其来源页，新建草稿单独操作；保留切页、切题和离开保护。档案先最多5次近期记录，再按真实题目回看过程，前次关系仅在确有绑定时显示；筛选、全表和来源观察按需展开。
- **公式、报告与帮助**：常用公式、即时预览及插入复用现有渲染器，同时接入嵌入工作区和旧独立表单；原始标记收进高级区。报告先真实摘要、完成条件、待评价、待复测及已核定关联，资料范围也限定计划；来源／评价展开，录入时间显示北京时间及UTC偏移，不改实际作答日期。成员权限和关联按需查看，帮助按任务给直达路径。
- **兼容、预览与格式**：旧GET／锚点保留，资料处理指向资料整理，旧业务POST／签名／下载权限保留。PDF响应和正文显示分开，超时／重试／打开／下载可用；快照可鉴权即时生成逐页图片，原文件不变。固定双格式路径明确“同时生成”，生成、审校和Word实开状态分别呈现。预览弹层支持关闭、焦点限制及返回触发处。
