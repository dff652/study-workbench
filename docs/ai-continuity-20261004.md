# AI 连续核对与整页状态

日期：2026-10-04。承接[几何与教学图](geometry-workflow-20261004.md)，仅本机源码、合成验收和文档；不提交／推送、不升级 36、不写 NAS、不调用真实模型或安装依赖。既有几何与 SOP 批次保留，统一交付另行安排。

## 使用流程

模型配置、外发范围、所选来源及执行请求保持明确。未请求执行的排队任务不自动发送；已请求执行或运行中的页面每 3 秒刷新。结果返回后直接进入核对页，原提案、精确来源题目／作答和原图可回看。家长逐项核对，勾选确认并填写依据，点击“确认并保存”；系统在同一事务生成内容版本并记录原生接受决定，省去默认的“应用草稿”中间步骤。

已确认后可进入下一条可确认任务。每份建议分别确认，尚未提供多个任务的一键批量确认；导航检查最近 100 条待核对／已应用任务，较早任务可通过其地址回看。GET、刷新和进入下一条都不保存、不接受、不执行模型。不完整内容无法发布，失败事务不留下半个草稿或确认，提案仍保留。来源、内容头、依赖或审核状态变化时拒绝旧页面；精确重复请求只返回历史回执，不重新发布已撤回内容。

旧 `apply` 服务／POST 兼容显式暂存草稿，不授予接受状态；新页面也可确认当前有效的旧草稿。实际任务类型为题干、知识、评价、变式四类；分类和解析仍是题干提案中的建议字段，不能算另两种已完成的模型能力实测。

## 内容和来源

- 空白题干确认后追加完整题目，原空白与原图保留。已有非空印刷文字被建议改动时，仅接受印刷文字订正建议；不直接改题、不认定孩子答错。应用勘误仍走已有独立订正流程。
- 知识确认同时接受条目，并建立／接受到明确选定的精确题目版本的 `knowledge_question` 关系；保留来源区域，知识／题目／原图双向查询。不自动确定主方法、题型或掌握。
- 评价固定既有作答和题目修订。新评价分别保存，五维 unknown 与原因保留；不创建作答、不改课堂／提示／独立来源、不推断独立成功。
- 变式继续使用已有来源、作者与数学发布门槛，仅任务创建者可确认；不扩大证明能力。

`app/ai/review_services.py` 编排事务、授权、上下文和回执；核对表单／视图／模板只承载明确人工动作。签名绑定家庭、任务和确认用途；比较提案哈希与输出审核指针。任务固定配置和外发声明可折叠回查。

## 整页阅读与分区

资料列表及原图页显示阅读／待补状态。原图页进入“整页阅读与分区”，模型关闭时也可记录未阅读／已阅读／待重拍、待补分区／已逐项核对分区、待补事项和本次人工依据。

分区类型为理论／知识、印刷题目、图示、手写内容、看不清／来源未知。复用四方向框选、缩放／移动和键盘坐标，保存整数像素的显示坐标／方向／预览 SHA、原图像素坐标与原图 SHA。整页服务与原生约束均拒绝分数像素；数学上为整数的数值规范化保存，既有题目区域契约不改。没有区域也可保存未阅读或待重拍；存在未知、待补事项或尚未阅读时不能标为分区核对完成。

`PageReadingRevision` 按页追加，固定前版、家庭、作者和原图 SHA。原生数据库约束拒绝更新／删除、跳版／错前版、跨家庭／原图、未授权作者和错误坐标映射；服务同时校验原图／预览字节。历史状态、分区和待补事项可回看。

整页状态是人工资料清点，完成由家长声明，不自动证明框覆盖整幅照片或题干／答案正确。分区不自动创建知识条目、题目来源、作答观察或评价；手写作者和独立性仍须另行核定。模型 schema 不返回自动分区坐标，本轮未增加自动整页 OCR 或完整性判定。
