## README 设计决定

- 受众：家庭资料整理者和自托管实例维护者。
- 价值：照片成为可追溯题目，每次真实作答、评价与复测单独保留。
- 证明：当前工作树的实际 PC、匿名解析排版及联合恢复证据；不使用另一实现的数量，不展示虚构掌握率。
- 第一次成功操作：Python 3.12 运行 26 项纯标准库核心契约，然后按容器说明启动私有网页。
- 视觉：纸张白 `#f8fafc`、正文蓝灰 `#0f172a`、主色 `#1e293b`、来源绿 `#0f766e`、连线 `#64748b`；系统字体、20 单位圆角、2 单位描边，沿用工作台的原图选区与证据关系。
- 静态 SVG 是仓库另一工作树已有的自编关系图，只复用该文档源码；不复制其应用实现或验收结论。原图↔题目↔知识与两条独立流程是图的全部内容，必需标签在 360 宽度仍可读。
- 命令、正文、限制和链接保持 Markdown；不生成位图人物，不加动画、署名、宣传链接或 showcase PR。
