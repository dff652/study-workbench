| `documents/v2/*/content.json` | v3 当前实际读取的两份历史内容 | 随迁移显式导入，不能只复制 v3 脚本就认为可以复现 |

建项盘点时，历史运行环境含 ReportLab、python-docx、PyMuPDF 和字体处理组件，新项目尚未安装渲染依赖。2026-10-02 A2 已在项目 `.venv` 固定 ReportLab／python-docx／fontTools 等依赖，新增项目测试和打印快照；新渲染器不使用 PyMuPDF，具体见[打印契约](export-contract.md)。
