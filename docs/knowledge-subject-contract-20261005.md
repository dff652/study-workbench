# 三种资料模式与学科契约（2026-10-05）

用户同意先交付 Web UX，再设计并接入知识点讲解和学科分类，最后以小批次验收。本批次从已部署 UX 的源码与文档开始，使用独立功能工作树；正式服务升级、源码提交与推送分别登记。

## 三种输出

| 模式 | 内容与入口 | 保存及生成 |
| --- | --- | --- |
| 知识点讲解 | “知识与题库”的讲解工作区；结论、条件、依赖、完整证明或解释、限制与来源；不是题目或学习者事件 | 独立知识修订；清单、逐知识点、分讲、合集，各选 PDF／Word |
| 逐题讲解 | 保留题干、小问、本讲／其他方法、公式、图示、答案与勘误 | 保留 v1／v2 历史；新增带学科快照的 v3，沿用逐题／分讲／合集 |
| 五册与练习 | 现有知识整理、分类索引、证据、无提示练习、家长答案 | 继续现有五册工作流；答案及讲解图示不能进入无提示练习 |

文档中心区分三个模式，主导航保持七入口。新知识讲解使用现有权限、原图、图示、后台任务、不可覆盖文档及下载机制；不导入第二套渲染器、上游 CLI 或家庭生成文件。

## 学校学科与讲解依据

学校学科为人工分类：未分类、数学、语文、英语、物理、化学、生物、历史、地理、道德与法治、科学、其他。分类追加修订，记录作者、理由、前版与请求身份；同键重放、过期版本冲突及跨家庭权限沿用现有规则。旧资料没有分类修订时显示“未分类”，不补造历史。

资料列表和文档选择可按最新学科筛选；题库的“资料学科”以实际来源所属资料筛选，来源不明的独立条目不推断学科。内容修订保存独立学科快照，后来分类不改写旧正文或旧输出；分类变化会使已排队内容的来源检查过期，需比较并另存。

每讲另由作者选择讲解依据类别：数学证明、科学观察、语言分析、人文证据。学校学科不自动确定类别。类别限制可用性质：数学为定义／定理／方法，科学为定义／观察经验结论／方法，语言及人文为定义／文本解释／方法。程序验证结构和类别，正确性仍需内容作者审核。

## 知识内容与审核

独立 `swb.knowledge.v1` 包含标题、学校学科、学习层级、讲次、知识条目和输出偏好。条目保存稳定本地 ID、原页／基础／补充归属、原结论、完整结论、定义、条件、已有知识修订的可选关联、依赖、原图来源、解释步骤、勘误与未知。依赖必须存在且无环；旧知识关联可回读，确认及生成只接受当前已发布版本。

草稿允许缺内容；生成前每条必须有“先想什么、方法或构造及目的、完整推导或依据、结论、易错与限制”五部分实质文字，结论重述完整声明。原页条目必须绑定真实原图文件名和字节，基础或补充没有原页时明示。每步可附原生公式、来源图／裁图／辅助图以及显式分页；原图与裁图按现有 RGBA 像素验证，辅助图不能冒充原图。

上游固定 `study-material-workflow` 本地已提交 `961f966f02f2c00e3c43b2dfd3e17ad19e345fa5` 的纯知识模型，记录原始与适配 SHA。其三份共享纯 helper 与原逐题固定版本字节一致，继续复用原 helper；旧逐题来源清单保持。知识编译先验完整上游契约，再转为 Workbench 原生打印内容。每条正文只测量一次，分讲和合集重用相同正文，目录按实际分页计算。

私人草稿与正式历史分开；正式保存追加版本，过期请求保留输入并比较，生成任务固定内容／来源／版本。取消与迟到 worker 不能恢复旧任务。内容与来源、学科依据、PDF 页面、Windows Word、macOS Word分别记录，绑定内容与生成配方；机器验证不自动填人工通过，失败阻止 ZIP 交付。未实开 Word保持未测试。

## 本批次验收与边界

验收先使用匿名数学、科学、英语及人文小样本，检查实际来源、有限依据、数学推导、组织方式一致、所有 PDF 页面、Word结构、ZIP字节回读、数据库原生防线、权限、冲突、旧历史与三种入口。另在独立空实例检查新增表及模式数据恢复。实际结果写入独立验收记录，不把上游结果填成 Workbench 通过。
