# Study Workbench

面向家庭的学习资料与作答证据工作台。计划把照片整理成可追溯的题目，关联方法分类、独立作答和复习记录，并继续支持纸上练习及 PDF／Word 导出。

当前阶段：**需求 v0.1 已完成独立评审，v0.2 由主代理补充复核；A0、A1a、A1b-P、A1b-I、A2 离线子集及 B1 人工 Web 子集已完成。登录、上传、框选、题干编辑和审核已通过本机合成验证；尚未部署应用。**

两条核心主线：

- **知识与题目组织**：知识库、题库、知识地图，以及知识点、方法、题型和题目的关联索引。
- **作答评价与学习跟踪**：手写过程评价、个人学习档案、逐次作答与复测历史。

上传、OCR、大模型与 agent、打印和备份支撑这两条主线。首版同时提供两条主线的基础人工流程，再加入 AI 辅助。

## 已有基础

- 23 张来源照片；61 道编号题，拆成 81 条小题索引。
- 六组方法：基础变形与换元、公式与通项、分数裂项、整数裂项、比较与估算、方程与新定义。
- 五份成套文档，每份包含 PDF 和 Word；PDF 合计 29 页。
- 手写证据评价、独立复测题、家长观察记录，以及可复用的文档渲染代码。

这些资料来自人工核对与编排。现有索引尚不是完整 OCR 题库；A1b-I 保留 81 条原行、91 个题目节点和 23 张照片，题干与坐标待补。数据库导入仅在自有临时实例验收，结束清理；本机私有来源包保留。B1 页面支持新人工资料，旧索引的知识管理界面、自动识题和学习记录页面仍待实现。

## 当前方向

先验证家庭自用价值，再考虑对外产品化。A0 补查支持复用现有分类／渲染成果及成熟组件，定制知识关联、证据评价和档案业务；候选应用目前作为流程参考，整体改造保留为待验证方案。A1b 已选定 Django 5.2 LTS／PostgreSQL 16，具备数据库持久化、审核事务及旧索引导入子集；供应商、OCR、部署与完整应用适配性仍需实测。A2 离线渲染已完成，五份 PDF 共 29 页、Word 62 个可编辑公式通过回归；Word 办公软件实际分页待验。B1 人工 Web 子集已验证，下一步建议 B2a 知识条目与关联管理，实际验收状态见 DEV_STATE。

需求已包含生成知识体系：FR-15 允许人工建立知识条目或由 AI 生成待审草稿，FR-16 组织知识点、方法、题型及题目的双向地图。首版使用分类树和关联列表，AI 草稿需要来源及人工确认；知识管理页面属于 B2，模型生成属于 C1／C2，当前尚未实现这两部分。

最终交付方向是 Docker Compose 管理的容器化服务，浏览器访问；应用、数据库及必要的后台任务分开运行，照片和个人记录独立持久化。交付包括源码、构建／启动配置和升级、备份恢复说明；部署设备、数据路径与镜像发布方式待确认。详见实施分工第 5 节，当前没有应用容器部署；A1b 验证仅使用隔离的临时 PostgreSQL 测试容器。

首版流程：上传照片 → 框选题目 → 人工录入或 AI 草稿 → 关联知识点、方法和题型 → 审核及打印 → 评价手写过程并记录个人档案。变式、复习安排与学习报告属于后续阶段。

照片、个人学习记录和导出文件放运行数据目录，不进入源码版本控制。当前真实照片副本和导入包保存在被忽略的 `data/`，原照片、历史输出与脚本未改动；依赖只装入 `.venv`，没有调用付费推理 API。

## 离线验证

A1a 领域模块在 Python 3.12.3 下已验证，不依赖第三方库。在项目根目录运行：

```bash
python3 -m unittest discover -s tests/domain -p 'test_*.py' -v
```

26 项测试覆盖双向来源、多次作答、未知、勘误与版本冲突，使用[虚构关系包](tests/fixtures/domain/synthetic-v0.1.json)。审核状态是输入快照，JSON 包不包含真实图像或完整审核／备份记录；完整设计与实现边界见[核心契约](docs/core-data-contract.md)。

更新日期：2026-10-02（Asia/Shanghai）。

## 持久化验证

安装 [requirements.txt](requirements.txt) 到项目 `.venv` 后运行 `.venv/bin/python scripts/run_persistence_tests.py`。仅使用虚构数据和已缓存的 PostgreSQL 镜像，验证数据库关闭网络、不发布端口并清理自有临时容器；默认不启动 Web 进程，包含服务及 HTTP 用例。配置、审核语义与完整交付边界见[持久化契约](docs/persistence-contract.md)。

追加 `--legacy-package <包目录> --data-root data` 可在同样的自有临时数据库验证本机索引。包准备、显式目标导入和未知处理见[导入契约](docs/legacy-import-contract.md)；默认验证不读取真实照片。
