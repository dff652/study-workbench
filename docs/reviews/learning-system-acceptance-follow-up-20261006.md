## 整改采用的共同规则

1. 家庭／学习者范围与作答分析筛选分开：真实待复测任务不受作答日期筛选影响；筛选改变不能追加行动卡或虚构无计划。切家庭／学习者立即清除旧范围内容，只展示当前加载／成功／失败状态。
2. 学生／家长模式是呈现偏好，权限仍由服务端角色与对象归属决定。只读成员不能因进入学生模式获得作答写权限；需要协助时给真实可执行入口。两种模式及默认入口先用可点击原型确认，再实施。
3. 保存作答、确认计划关联、完成计划和评价是独立动作。可以在一个任务流程中串接，不自动产生评价、掌握或额外作答；没有条件／日期证据保持未知。
4. 同日时间线使用真实前次关系和明确的录入次序，不按“首次／订正／重做／复测”的名称强排。未记录具体作答时刻时明确标注排序依据；未知日期单列。修改旧评价或旧作答修订不能把旧事件自动变成最新作答。
5. 文档统一成果读取与搜索，保留练习、知识讲解、家长解析、五册各自的正式内容、生成和审校规则。保留[原 IA 决策](ux-remediation-implementation-20261006.md)；统一入口不等于合并正式 schema。
6. 不为了首页好看增加正确率、掌握率或连续学习指标。UX-C01～04 保留原定义／延后决策，批量审核不成为本轮必做任务。
