# 知识、学习与打印的 Web 业务契约

更新：2026-10-03。本轮实现和最终验收状态见 DEV_STATE.md；此契约不把未完成的模型实测算作通过。

## 共享记录

Knowledge、Method、QuestionType、Question、SourceObservation、Attempt、Assessment 和 Erratum 继续使用核心契约及持久化层唯一身份。页面通过 household 锁、活跃账号与角色复查、带用途／对象签名的编辑和审核上下文写入。完整依赖头及上一审核决定过期时拒绝；HTTP 请求凭据在生成新 UUID 前重放，成功重试不能追加重复记录。

内容 payload 的审核字段是原始快照，实际状态来自 ReviewProjection 和发布指针。新草稿不能改写旧内容／哈希／来源或覆盖旧发布。关联固定题目及节点精确版本；正式当前地图仅使用实际发布且端点仍有效的关系，历史关联另行回看。三类节点分别管理，六方法组不是强制封闭分类。

节点筛选使用同一正式发布关系判定，不能把待审核、撤回或过期关系当作当前地图；旧索引的方法筛选仍明确保留旧草稿标记。学习档案的题干、题号和分类按每次作答固定的题目修订读取，旧版本关联标为历史关系，不套用到同题新版本。

资料与主／辅助方法角色可和知识、题型、题号及审核条件组合。资料筛选使用当前 QuestionSource 或同家庭历史来源的确切区域修订锚点，支持勘误、合题和拆题；同 SHA 图片在不同资料中复用不构成资料归属证据。档案知识／题型筛选使用稳定 ID，名称旁显示身份后缀，实际日期、评价审核及错误条件可组合；无坐标锚点的未知来源不推断。

## 作答证据

档案关联的未知观察不等于确认作者。作者确认记录人员、时间和依据；实际日期未知保持未知，不用录入／上传日期填充。独立作答、提示后完成、课堂笔记、抄录和来源未知分别记录，每次首次／订正／重做／复测使用独立 Attempt，修订也保留旧版。

评价分别记录答案、方法、过程、计算和符号，引用精确原图区域；观察、推测及无法判断分开。独立成功由当前有效 Attempt、确认作者的当前清晰观察、已知且一致的实际日期、明确无提示与独立来源、实际已接受的当前评价共同筛选。空白、看不清、未知、课堂或提示记录不能变成独立成功；过程与答案矛盾亦不能计成功。

题目存在新的待审草稿时，仍可选择原正式发布版本记录作答或创建复习计划。页面分别捕获正式版本与内容头，提交时核对发布指针和实际内容头；页面打开后版本变化则拒绝，不能把旧发布版本误当作当前内容头。

## 打印与教师答案

家长答案是独立的 TeacherAnswerRevision，固定题目版本、解析、公式、依据及来源；AnswerDecision 追加审核。它不是学习者答案或 Assessment 推断。新答案草稿／拒绝保留以前已接受版本；版本／审核过期不能覆盖。数据库禁止答案、审核和 ExportSnapshot 更新删除。

`/prints/` 仅选当前已审核题目。独立练习包含题目与留白；用途契约阻止答案、分类、方法或评价进入独立练习。家长答案导出要求每题存在已审核教师答案。知识整理与分类索引仅使用当前有效发布关系及节点。

ExportSnapshot 记录题目内容哈希、审核决定、原图区域、关联／节点／答案版本和文件清单 SHA。生成输出在 SWB_DATA_ROOT 下私有快照目录，重复生成校验并复用；变更内容生成新快照，不覆盖历史。下载再次检查活跃账号、对象归属及全部文件哈希；认证页面及下载 no-store。完整备份仍须数据库与私有文件联合备份，不把单份打印清单当完整归档。

数字表达式和分数／行／幂可转成 Word 原生公式；算术复算只支持有理数四则及有限整数幂，不是全面证明。超出支持集拒绝并提示来源图片回退，不可静默丢失；实际 PDF／Word 回归及办公软件分页按验收报告记录。

负底数／负变量与嵌套幂保留可见分组，`(-2)^2`、`(-x)^2`、`(x^2)^3` 不得渲染为未分组的另一表达式。知识整理／分类索引快照同时固定关联与节点各自的实际审核决定 ID；后续撤回或重新接受不改写已生成快照。

题目与知识可另填版本化 `display_markup`，用封闭的重点、公式或原图区域标记输出 PDF／DOCX；去标记后须与正文一致，省略时旧 JSON 与哈希不变。独立练习中的图片还需本题版本的人工无提示确认 `image_print_confirmed`，默认未知；编辑不沿用确认，讲义勘误清除旧排版和确认。具体语法、反例及验证见[缺口补齐记录](gap-closure-20261003.md)。

## 讲义勘误

Erratum 保留印刷原文、订正文本、依据、区域及目标精确题目版本。接受勘误后才能生成新的题目草稿，印刷原文不变，仅工作文本订正；新的题目仍需单独接受。旧作答继续固定旧题目版本，勘误不生成或修改学习者错误评价。目标题目已有新版本时拒绝直接套用旧勘误。


## 合拆题、变式、计划与报告

合题与拆题产生新题目草稿和不可改写的 QuestionLineage，固定输入／输出精确修订及来源；原题、历史作答不改写。跨页来源可以合并，缺口原样保留。

人工输入的派生题号另由不可改写的 QuestionLabel 固定到目标精确修订，并记录录入账号与时间。跨资料合题或来源尚无单一资料归属时仍保存题号，不伪造 QuestionSource.material；后续拆分、索引、作答选择及讲义勘误分别保留对应题号。既有丢失的输入不能自动推断补回。

变式必须来自实际等待复核的 ModelRun，记录精确父题、目标方法、原始提案及确定性算术结果；Origin.AI 和不可改写的 VariantProvenance 保留出处。继承父题区域的用途为 OTHER，代表生成依据，不表示新题印在原图。应用仅生成草稿；所有通用题目审核入口调用同一发布门槛，源题／方法／依赖／审核指针变化时拒绝发布。当前变式内容固定为原模型提案；需改题干时退回后重新生成或人工录入另题，不静默修改生成依据。

变式提案只能由创建该任务的成员应用。出处记录的来源版本为父题与模型所选来源的有序去重并集；不能因为模型只选择了目标方法，就遗漏父题。审核仍遵循家庭审核角色规则。

StudySchedule 固定学习者和题目版本；改期、取消、完成均追加 ScheduleRevision。完成事件引用真实同题精确版本作答，不自动证明独立掌握；实际日期与记录日期分开。报告列出全部历史评价的实际审核状态、撤回及替代记录；仅有效、当前、直接观察且已接受的评价参与已见方法或重复错误汇总，未知保留，不创建置信度／掌握分数。网页、JSON 和带来源版本的 PDF／Word 均可查看报告。

模型配置、任务／预算和离线验证范围见[模型说明](model-configuration.md)。真实供应商调用由用户后续配置测试，本轮禁止将 mock 质量称为识别准确率。

## 本地保留与人工耗时

`/operations/` 按家庭和角色显示本机数据策略及人工记录。所有者追加保留策略，默认不设到期归档或退役；保存策略不会触发删除，维护 CLI 默认只预览。显式执行只处理已登记的打印快照：完整校验并归档后再移除原导出目录，保留不可变归档／退役记录及来源元数据。下载已退役快照返回 410，同一内容快照不能被重新导出悄悄复活。原图、领域历史、模型提案不在此维护范围。

所有者或审核者可追加人工估计耗时，固定当前已接受题目版本和可选的同题当前作答。手工录入与模型结果人工修订分别记录；编辑凭据过期时拒绝，成功重放不重复入库。它不代表精确测量或孩子的作答时长。独立退役账本与旧备份恢复核对步骤见[本地数据策略](local-data-policy.md)。
