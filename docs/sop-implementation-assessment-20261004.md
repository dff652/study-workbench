两处需要校正对 SOP 的理解：

1. [网页上传脚本](../app/web/static/web/uploads.js)已将多图选择拆成逐张请求。JPEG／PNG 单文件上限 12 MiB、像素上限 1600 万；不能把 12 MiB 推导为整批总量上限，也不能把旧导入的 32 MiB／4000 万像素当作 Web 限额。
2. [原图区域排版](../app/printing/services.py)可以输出带来源的图片回退，独立练习还要求该题版本明确确认无提示。缺的是程序重绘教学图的正式适配与几何五册验收，并非系统完全不能打印图片。

## 面向家长的流程调整

主入口应为“上传／选择资料 → 整理并对照原图确认内容 → 生成五册并检查版式 → 下载／交付”；作答与订正从题目或学习档案进入。内容确认与输出检查分别保留，内部应用、版本和发布步骤由系统衔接。首次独立题卷与家长答案分别构造，证据不足时评价册保留待测。五册计划应允许批次标明不适用册别并说明原因，不强造学习判断。

父题、区域、版本、模型任务和审核链保留在服务端，界面使用可读题号与内容。手动编辑可在明确的“保存并确认”动作中追加内容及确认；AI 返回后自动展示核对页，家长可以批量确认已核对项目，减少独立的“应用草稿”搬运步骤。并发变更、缺口、未确认和未知继续阻止错误发布；这项调整尚未实现。

模型、预算和外发配置放设置中，首次／范围变化确认保留；普通家长不必操作内部版本 ID、请求标识或 worker。轻量成员管理作为配套任务，孩子档案不等同登录账号。shadcn-admin 可供界面参考，前端替换不是几何适配或五册流程的必要前置条件，本轮没有安装或运行候选。
