## 页面组织

先展示当前要做的事，再展开完成任务所需的信息。学习者身份始终清楚，普通筛选、历史、来源细节和家长维护不占满首屏。折叠只改变呈现，不改变权限、证据规则、原图或正式历史。

| 功能页 | 首层 | 后续层 |
| --- | --- | --- |
| 学习总览 | 三个学习动作与当前学习者 | 作答记录概要 → 筛选／来源统计 → 具体证据 |
| 资料整理 | 找资料、选资料、当前整理步骤 | 上传原图／核对题面／整理讲解／整理任务，按当前操作显示 |
| 知识与题库 | 可练习题目与搜索 | 知识／方法／题型目录，家长整理与审核 |
| 学习档案 | 学习者列表或当前实际作答 | 新记录入口、证据详情、历次修订／人工核对 |
| 进度与复测 | 当前复习计划 | 资料整理进度、学习证据与已完成历史 |
| 文档中心 | 找到并查看讲解 | 制作练习、编辑讲解、生成文件与历史版本各有入口 |
| 设置 | 当前设置分类和已有成员 | 新建账号、家庭切换、模型配置、审计与运维细节按需打开 |

普通表单保留必要字段和明确提交动作；长说明用补充帮助，错误与未完成条件直接显示。折叠／任务切换保持输入节点，离开仍提示未保存状态。链接锚点及表单错误所在层自动展开。复习页优先显示待完成计划，完成／取消和逐次历史分别展开。

主代理最终浏览器验收 58 状态、49 模板和 28 组检查通过；七入口均检查 390／1440，代表页面另验 1280／1920。实际验证帮助的键盘与触摸、折叠切换后输入保持、三条业务闭环、空白家庭、只读、过期会话，以及新建账号错误自动展开且不新增账号。截图和日志在忽略目录，主代理查看七入口、讲解查看／编辑及帮助截图。它是合成任务可操作性验收，真实儿童试用与 Android 真机仍需单列。
