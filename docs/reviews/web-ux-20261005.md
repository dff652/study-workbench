## 范围与实现

独立工作树 `codex/web-ux-improvement` 从 main `4b70f03` 开始。验收结束时尚未提交或更新目标服务；随后获授权的本地提交及交付 review 见 [交付记录](web-ux-handoff-20261005.md)，运行升级另行签收。原工作区、参考分支和运行实例保留。三名 Luna6 分别负责资料／题面／讲解、学习档案、进度／复测；主代理负责公共框架、其余模板、共享接口、整合审查与实际验证。

- 六个业务入口常显，设置置底；家庭／学习者使用一条紧凑全局上下文。主区取消整体限宽，列表、详情和对照编辑使用可用空间。
- 资料、讲解、档案、进度、知识题库、文档和相关设置使用明确的工作区 Tab。切 Tab 保留面板和输入；键盘移动焦点后手动激活，错误与恢复字段自动打开所在面板。旧业务 URL 的服务端人工流程仍可直接使用。
- 资料选择、搜索和页码写入 URL，选中资料可独立读取；切换资料追加历史，刷新和前进／后退保留定位，家庭切换或无效范围回退会清除原定位。
- 题面、讲义勘误与整页阅读分别跟踪未保存输入。销毁输入前确认，取消继续保留；保存只清本表单状态，背景重取失败保留其他表单，迟到响应期间锁定会重置的题目编辑区。
- 导入继续执行原有严格解析、资源路径和来源匹配。协议、内部字段、哈希和原始对象换成业务文案；未知及额外内容仍明确待核对。草稿与正式保存、错误和冲突分别呈现。
- 复测逾期由服务端按本地日期和最新操作判断，客户端使用该标记。题干、答案和独立掌握的语义、原图、五维评价、历史、权限、CSRF 及实际作答绑定保持；没有新增迁移或改变生成器／数学渲染器。
