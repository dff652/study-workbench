本轮获授权实施[核查清单](requirements-implementation-audit-20261003.md) T-01～T-07。真实供应商配置和调用仍由用户后续手动进行。此文档记录共享契约、工程验收与人工待办；运行、提交与部署分别以 [DEV_STATE](../DEV_STATE.md) 的实验证据为准。

## 版本化排版契约（T-01）

题目 `QuestionRevision` 与知识点 `KnowledgeRevision` 增加可选 `display_markup`，分别对应 `working_text` 和 `definition`。原文、资料勘误、学习者作答和评价保持各自身份。字段为 `None` 时不进入 JSON 和内容哈希，旧版本的字节形状与哈希不变；只有明确标记的新增兼容字段允许旧包省略，其他必填字段仍严格检查。填写排版后字段进入版本哈希，修改必须追加修订并重新审核。

输入为封闭语法：`**重点**`、`==标记==`；整行 `[[math:1/2]]` 表示有界四则／幂公式，支持负底数与嵌套幂。整行 `[[image:1|原文]]` 按同一修订中证据引用的 `sequence` 选择确切原图区域；不接受路径或 URL。去除标记后的文本必须与相应正文一致，排版不能借机添加答案或改写题干。不支持的数学符号可选择来源图片回退；图片仍附原图 SHA、确切区域修订及替代文字。

排版由业务打印转换为封闭 `p`、`math`、`formula_image` 块，分别生成 PDF 和 DOCX 原生 OMML。未填写新字段的历史文本按字面打印，不自动重新解释 `**` 等符号。应用讲义勘误时清除旧排版，防止旧式样携带已更正的文字；可在后续修订填写与更正正文相同的新排版。已生成快照保持原样。

独立练习的图片回退另需 `image_print_confirmed` 人工核对，默认未知，确认为真时进入题目版本哈希。录入者必须核对本版全部打印图片没有作答、提示或方法笔记；含混排手写的原图区不能自动视为纯题干。每次编辑与勘误均须重新核对，缺确认时独立练习拒绝打印图片。浏览器 CRLF 与 LF 仅在排版正文一致性检查中视作等价，原文及旧哈希不被改写。

实际 PDF 目视发现了既有字体缓存缺陷：不同内容的 CJK 子集具有相同内部字体名，ReportLab 除注册别名外还按该名称复用字体，连续导出会使后续文档缺字。反例在修复前稳定失败；注册时现以字体 SHA 区分内存字体身份。生成器升为 `study-workbench.renderer.a2.v2`，新导出不会复用旧 v1 文件，已生成的历史快照及其哈希保持不变。发现旧 PDF 缺字时须重新导出，不能覆盖旧证据。

## 检索、手机与外发（T-02～T-04）

共用区域编辑器提供图片内 1～4 倍放大、移动／框选与重置；90°／270° 的放大后框选仍映射回原图。知识索引可按资料、知识、题型、题号、审核和主／辅助方法角色组合查询；档案按稳定知识／题型 ID、日期、评价审核和错误查询。资料筛选沿确切区域修订保留勘误及合拆来源，不用相同图片 SHA 推断跨资料归属；同名节点与历史关系分别显示。

每个模型配置版本保存直连／网关／未知、已知上游名单或显式未知、留存说明或显式未知、外发范围及确认人／时间。三项声明要求明确选择，启用云处理的新增版本必须手动确认。任务保存完整配置快照；排队、领取和发送前分别核对，配置关闭／被替换、来源过期或执行者失去权限时禁止发送。带完整新确认快照的任务在发送门槛前取消时释放预留；通过门槛后结果未知，或旧运行缺少该快照时，保守保留未知费用。应用按八类数据展示生命周期，不把本机退役称为供应商已删除。

## 本机派生契约（T-05）

每次裁切、手动矩形遮白或对比度增强生成新的 `ImageDerivative` 和 PNG 文件，绑定固定资料页、原图记录、原图 SHA、操作版本、显示旋转及输入坐标、映射后的原图坐标、处理参数、输出 SHA／尺寸、创建者与时间。文件权限为 `0600`、目录 `0700`。同一请求幂等，不同内容复用请求标识被拒绝；操作自身提交事务，失败会清理它独立 UUID 路径下的新文件，不能删除其他成功记录复用的字节；数据库原生触发器禁止改写／删除派生记录及插入不匹配原图。

显示坐标先映射回原图，裁切输出固定保持原图方向。遮白只处理人工明确给出的矩形，可能同时抹掉印刷文字；对比度增强可能丢失灰度和颜色。二者均不恢复看不清或被遮挡的原文，不自动成为题干真值或孩子掌握证据。原图和既有派生记录保留；备份／恢复沿用完整私有文件清单，包括派生 PNG。
