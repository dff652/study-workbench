### 学习总览

目标：先判断当前任务、近期记录与待补事项。结构：当前学习者与范围 → 近期行动 → 真实记录摘要 → 最近作答 → 需关注与依据。少量记录使用自然高度，指标不补造。

| 编号 | 优先级 | 问题及影响 | 整改方向与任务 | 依据 |
| --- | --- | --- | --- | --- |
| OV-01 | P1 | 首屏缺少按实际任务组织的学习入口。 | 按近期复习、继续上次任务、记录作答组织首屏，统计放在次级摘要；练习入口默认展示已核对且可用于练习的题目。 UX-03、UX-09 | E/W |
| OV-02 | P1 | 无结果筛选被描述成没有学习历史。 | 分别设计首次无记录、当前筛选无结果和缺少评价三个状态，给出记录、清除筛选或补充评价动作。 UX-04 | E |
| OV-03 | P2 | 摘要分散，两栏失衡，待核实原因重复。 | 使用有限宽度的紧凑统计区；各模块按内容高度结束；按作答分组列待补项，展开后查看具体维度与完整原因。 UX-05、UX-11 | E/W |
| OV-04 | P2 | 筛选与统计单位不够清楚。 | 保存日期与来源筛选，标明作答“次”和题目“道”；同日日期间隔可汇总说明。 UX-04、UX-10 | E/W |
| OV-05 | P2 | 标题、正文、数字和行动权重接近，系统字段与长规则抢占学习任务。 | 统一字号与状态；先展示当前任务和摘要，再展开依据。 UX-05、UX-06 | E/W |
| OV-06 | P2 | 缺少最近变化与需要关注的组织方式，不能快速判断近期情况。 | 先补真实近期记录；正确率、掌握和趋势按候选规则决定。 UX-12、UX-C01～UX-C03 | W |

### 共同设计规范

以下数值是实现起点，应在真实中文内容、窗口、键盘与缩放条件下复核，不能把某个固定宽度套给全部工作区。

| 范围 | 设计起点与行为 | 验证重点 |
| --- | --- | --- |
| 内容与栅格 | 常规主区最大宽度 1360～1440 像素，受可用空间限制；设置可 900～1100；12 列、4∶8／5∶7 或纵向自然高度。 | 1280／1440／1920 无整页溢出；原图和复杂表格有自己的操作空间。 |
| 字体与间距 | 标题 20～24、模块 16～18、核心数字 28～32、正文 14～16、辅助 12～13；8／16／24／32 间距，正文行高约 1.45。 | 中文长名称、说明与 200% 缩放可读，不靠极小字号塞内容。 |
| 卡片与表格 | 圆角 8～12、边框优先；标签高约 22～24，行高 44～52；hover、行详情与末列操作明确。 | 信息少不撑高；行内按钮与选择不误触导航，键盘可达。 |
| 状态与按钮 | 标签含文字和图标；已核定、条件、评价和计划分别表达；一个强主操作，次级和危险操作分开。 | 已确认不等于掌握；待核对不等于待复测；无数据与未知不等于错误。 |
| 空状态与加载 | 发生什么、原因、下一步；首次、无结果、缺项、未评价、失败和加载分别呈现。 | 每类有合适且有权限的动作，失败不伪装为空，不能凭少记录给肯定评价。 |
| 表单与导航 | 已有内容优先，创建按需打开；常用筛选与更多筛选；范围可恢复，保存／核定／生成分别反馈。 | 刷新与返回不丢范围；离开不静默丢输入，不重复写事件。 |
| 来源与证据 | 原图控件覆盖定位与坐标统一，缩放／旋转可保存；主区摘要，完整来源和修订按事件展开。 | 照片保持原样；不同作答不误合并，未知可保留，历史可回看。 |
| 敏感维护 | 权限与费用等关键条件就地说明；改变数据或账号的操作按现有服务端规则确认和反馈。 | 不为了设计增加删除、清理、外发或权限；策略显示范围与实际一致。 |

### 业务真实性约束

一次独立成功、完成计划、读讲解或生成答案均不能自动认定掌握；题干正确、答案正确与独立完成分别记录。正确率必须有有效评价与分母，进度必须有目标集合，日期未知不补造。来源观察不是学习成绩，资料错误不是学习者错误。资料与学习范围分开，版本、人工确认和原图来源完整保留。关闭模型时人工主流程仍可用。

### 实施定位

先由 UX-00 核对部署与本地来源。当前候选模块为 frontend/src/features/evidence（总览／档案）、content 与 materials（资料）、progress（复测）、solutions 与 materials（文档）、workspace（嵌入页面），共用 components、styles 和 routing。知识及设置入口需定位实际服务端页面／表单；不得仅凭目录或旧镜像身份断言故障根因。
